# Get Off My Lawn — Бот

> [🇬🇧 English](README.md) | 🇷🇺 Русский

Бот на компьютерном зрении, который сам играет в аркадный шутер **Get Off My Lawn**. Он захватывает окно игры, находит синих инопланетян по цвету, оценивает, какая дорожка опаснее всего, и управляет персонажем с клавиатуры, поддерживая бесконечный ран — перезапускается после смерти и заходит на склад за апгрейдами между забегами.

## Возможности

- Живой захват окна игры по заголовку (без записи экрана и внедрения в процесс)
- Детекция инопланетян по цвету (HSV) внутри перспективной трапеции газона
- Оценка угрозы по дорожкам с памятью и затуханием (переживает белую вспышку подбитого врага)
- Обработка широких целей (машина инопланетян распределяет угрозу по нескольким дорожкам)
- Автоперезапуск после смерти — отклоняет диалог «потратить 1000 шаров, чтобы продолжить»
- Автозаходы на склад раз в несколько забегов для покупки апгрейдов
- Детекция паузы: восстанавливается, когда игра показывает оверлей «нажмите, чтобы продолжить»
- Ресинхронизация позиции после любого внутриигрового клика мышью, сбивающего персонажа
- Режим `--debug`: лог угроз по дорожкам и кольцевой буфер аннотированных кадров
- Инструменты калибровки геометрии поля и шаблонов кнопок интерфейса

## Требования

- Windows 10/11
- Python 3.11+
- Запущенная игра **Get Off My Lawn** в разрешении 1920×1080

## Установка

```powershell
# Клонировать репозиторий
git clone https://github.com/DogNellaf/bot-get-off-my-lawn
cd bot-get-off-my-lawn

# Создать и активировать виртуальное окружение
python -m venv .venv
.venv\Scripts\Activate.ps1      # Windows (PowerShell)

# Установить зависимости
pip install -r requirements.txt
```

## Запуск

1. Запустите **Get Off My Lawn** в разрешении 1920×1080, окно должно называться `Get Off My Lawn`.
2. Один раз откалибруйте поле (см. ниже), чтобы бот знал расположение дорожек.
3. Запустите бота:

```powershell
python main.py
```

Бот наводит фокус на окно игры, убирает оверлей паузы и начинает играть. Держите окно игры видимым и поверх других — игра ставится на паузу при потере фокуса. Остановка — `Ctrl+C`.

### Режим отладки

```powershell
python main.py --debug
```

Раз в секунду печатает оценки угроз по дорожкам и непрерывно сохраняет аннотированные кадры в `calibration/debug_frames/`, чтобы после забега можно было посмотреть, что именно видел бот.

## Калибровка

Выполните перед первым запуском (и повторно, если меняется разрешение или раскладка игры). Каждый инструмент даёт короткий отсчёт, захватывает кадр при активной игре, затем открывает окно OpenCV для выделения.

```powershell
# Отметить четыре угла трапеции газона (ВЛ, ВП, НП, НЛ)
python calibrate.py field

# Захватить шаблон кнопки перезапуска «Играть заново»
python calibrate.py gameover
```

Вспомогательные скрипты для тонкой настройки:

```powershell
# Сохранить 20 аннотированных кадров геймплея в calibration/captures/
python debug_capture.py

# Сохранить 60 кадров экрана склада в calibration/shop/
python explore_shop.py
```

## Конфигурация

Настройки хранятся в `config.json` (создаётся автоматически при первом запуске из значений по умолчанию в `bot/config.py`). Основные поля:

| Ключ | Описание | По умолчанию |
|---|---|---|
| `window_title` | Заголовок окна игры для захвата | `Get Off My Lawn` |
| `lane_count` | Количество дорожек на газоне | `7` |
| `field_corners` | Углы трапеции газона (ВЛ, ВП, НП, НЛ) в пикселях клиента | калибруется |
| `alien_hsv_lower` / `alien_hsv_upper` | Диапазон HSV для синих инопланетян | `[105,80,100]` / `[130,255,255]` |
| `min_blob_area` | Минимальный размер блоба (px²), считающийся инопланетянином | `300` |
| `move_left_key` / `move_right_key` / `fire_key` | Клавиши управления | `a` / `d` / `space` |
| `step_cooldown` | Задержка между переходами по дорожкам (сек) | `0.0` |
| `powerup_enabled` | Использовать экстренные бонусы | `false` |
| `shop_enabled` | Заходить на склад между забегами | `true` |
| `shop_every_runs` | Забегов между визитами на склад | `3` |

Если мажорная версия конфига отличается от версии приложения, конфиг пересоздаётся из значений по умолчанию.

```
└── requirements.txt
```
